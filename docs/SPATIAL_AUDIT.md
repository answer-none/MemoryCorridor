# 空间设计与舒适性审计（SPATIAL_AUDIT v1）

> R12 · 对照 PICO 官方空间设计规范硬数值逐项核算 · 单位：dmm = 物理尺寸(mm) ÷ 观视距离(m)
> 规范基线：主要面板 2–3m（1–5m、≥0.4m）；正文 20 dmm / 最小 16 dmm；点击热区 ≥40 dmm；
