# devlog 录制脚本（3–5 分钟演示视频 + 每周开发日志）

> 用途：①比赛演示视频 ②每周 devlog ③申报文档素材。**GUI 手动操作——由用户按本脚本执行**，agent 无法录制。
> 工具：Win+G（Xbox Game Bar）或 OBS；分辨率 1920×1080；帧率 30/60 均可。
> 原则：每个镜头先拍 3 秒静止再操作；旁白照念或后期配字幕；NG 就重拍单镜头。

---

## 前置准备（一次性）

1. 打开 Unity 工程 → 确认场景 `Assets/Scenes/EditorScene.unity` → 按 ▶️ 进入 Play。
2. XR Device Simulator 键鼠位：**WASD**=移动，**鼠标**=视角，**右键按住**=射线，**左键/空格**=选中，**Shift**=冲刺（如有）。
3. 关掉无关窗口/通知；录屏前跑一遍操作热身。

## 每周 devlog 简版模板（30–60 秒）

1. 本周完成的一件事（画面演示 15s）
2. 一个踩坑或决策（口述 10s，例："OpenXR 和 PICO 的 loader 会在 Gradle 里撞车"）
3. 下周目标（字幕 5s）
存 `docs/devlogs/YYYY-WW-devlogN.mp4`；申报文档"开发日志"表引用。
