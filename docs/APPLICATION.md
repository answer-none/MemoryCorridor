## 1. 项目概述

**一句话**：把家的记忆挂回真实的房间里——在真实物品上挂一粒萤火般的光点，走近它先听见当年的声音，光点绽放成那一刻的回忆；太久不去看，记忆会慢慢褪色，直到你再次点亮它。

**体验闭环（5 分钟可完整演示）**：
挂（手机浏览器传照片/录音/日记 → 光点挂上老物件）→ 走（星尘路径引导、先闻其声、回忆重演四拍）→ 传（星河回顾墙 + zip 导出导入，隐私记忆永远留在本地）。

- 引擎链路：Unity 2022.3.62f3c1（中国版 LTS）+ OpenXR + XR Interaction Toolkit + PICO Integration SDK v3.3.3
- 目标设备：PICO 4 Ultra 系列一体机（MR 透视 + 全景双模式）；开发全程 Editor Play + PICO Emulator，无自备头显

## 2. 痛点与真实需求

- 家庭记忆散落在手机相册与云盘文件夹里，"照片属于某个房间某个物件"的空间语境被永久丢失。
- VR 怀旧疗法（reminiscence therapy）已被验证能提升老年群体情绪与认知参与（2024 系统综述 PMC11599890、2025 RCT PMC12109972）——但现有产品要么是机构级方案（Rendever），要么只是"照片相框"（Photo Gallery: Spatial Anchor Photo）。
- **我们要做的是消费级、家庭向、空间化的记忆策展**：记忆挂回它发生的地方，并对抗遗忘。

（完整竞品对标矩阵见仓库 `docs/RESEARCH_COMPETITORS.md`：Rendever / Alcove / Quest 原生 / immerGallery 五维能力对照。）

## 3. 创新点（对应评分"创新 25"）

1. **记忆褪色（遗忘作为机制）**——太久未回访的记忆，光点变暗、声音隔着时间（低通滤波）；回访即点亮。同类作品未见。
2. **回忆重演四拍时序**——现实退后 → 回忆绽放（分层伪 3D）→ 重返当时（空间音频+日记浮现）→ 温柔收回；不做相机接管，随时可跳过。
3. **星河回顾**——走读终点，碎片按路线连成星座；点星即重演。
4. **隐私分级的家庭分享**——私密记忆不进导出包、他人视角无光点；本地 zip 导出导入，零云端依赖。

## 4. 技术方案（对应"功能设计 25 + 完成度 10"）

- **数据流**：手机浏览器（局域网 HTTP）上传素材 → `PersistentDataPath` → appdata.json（成员/房间/碎片，Newtonsoft）→ RoomManager 数据驱动生成光点 → 走读/重演/星河墙全部由数据驱动。
- **渲染**：URP + 自研全景穹顶 shader（等距柱状投影倒置球）+ 磨砂 UGUI 面板（TMP 动态中文字体）+ Shuriken 星尘。
- **交互**：XRI 全手柄射线（悬停 0.3s 预览卡 → 扳机选中）；XR Device Simulator 键鼠同链路。
- **性能**：IL2CPP / ARM64 / ASTC / Linear；粒子预算 200；增量构建 0.8 分钟。
- **质量保障**：23 段自动化断言（smoke 批处理回归）+ Android 构建回归；38 天开发 6 次提交里程碑。
- 工程详情：`docs/TECH_DESIGN_V2.md`（架构/规范/排期/风险）；踩坑与决策记录：`docs/MEMORY.md`。
