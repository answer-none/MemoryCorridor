# UI 设计规范（UI_DESIGN v1）

> 作者：UI 设计师 + 美学大师 · R3 落地版 · 基调：暮色暖光（TECH_DESIGN_V2 §4.1）
> 原则：克制、一致、有呼吸感。所有组件共用同一套 tokens，禁止孤立调值。

---

## 1. 设计 Tokens

### 色彩
| Token | 值 | 用途 |
|---|---|---|
| `amber` | #E8A24B | 主强调：标题/描边/光点(图) |
| `cyan` | #5AC8E0 | 录音类/悬停态 |
| `cream` | #EBE1D2 | 日记类/正文墨色 |
| `warmorange` | #F28C59 | 混合类 |
| `warmred` | #C76B6B | 私密 |
| `bg/panel` | #1F1A26 @ 88% | 面板底（暮色深） |
| `bg/card` | #1F1A26 @ 92% | 预览卡/告示牌底 |
| `line/soft` | #E8A24B @ 60% | 1px 描边 |
| `glow/amber` | #E8A24B ×2 | 自发光 |

### 形状
- 圆角：面板 24px / 卡片 16px / 徽章全圆（R3 新增程序化圆角贴图）
- 描边：统一 2px `line/soft`；禁用阴影投影（VR 中显得脏）
- 层次：底板(88%) → 内容(95%) → 强调(100%)；重演期间全局压暗 30%

### 排版（TMP/TextMesh）
| 层级 | 字号(px @620 宽面板) | 色 |
|---|---|---|
| 面板标题 | 42 amber | 标题下 8px 留分隔线 |
| 日期徽章 | 24 cream@70% | 标题右下 |
| 正文 | 28 cream，行高 1.4 | 日记正文 |
| 预览卡标题 | 44(=0.012 char) amber | 单行截断 |
| 告示牌标题 | 52 amber；正文 34 cream | 行距 50px |

### 间距（面板 620×460）
- 内边距 32px；照片区上 44% 高；标题带 30–42%；正文 4–28%
- 关闭钮：右上角 (262,196)，直径 45px，暖红底+白 ✕

## 2. 组件规范

| 组件 | 构成 | R3 状态 |
|---|---|---|
| MemoryPanel | 圆角底板→照片区→标题+日期徽章→正文→✕钮 | 升级：圆角+徽章+分隔线 |
| HoverPreviewCard | 圆角底板→左缩略图→右标题/日期 | 升级：圆角+底板描边 |
| WelcomeBoard | 圆角底板→标题→三行引导（行距 50px） | 升级：圆角+标题分隔 |
| LightPoint | 内核球(发光)+外层 glow 球(1.5×, 半透明, 同色) | 升级：双球光晕 |
| StarNode | 星球+Thumb+Label（label 带微底板） | 保持 |
| StardustBeacon | 辉光球 | 保持 |

## 3. 交互反馈
- 悬停：预览卡 0.3s 淡入（现实现为直接显示，淡入列入 R4 打磨）
- 选中：chime 音效 + 光点 highlight 变青蓝（已有）
- 面板出现：定位于视线前方 1.5m 固定（防眩晕），✕ 或走开即收
- 引导告示牌：首条记忆选中后收起

## 4. 禁忌清单（美学否决权）
- ❌ 纯白/纯黑大面积；❌ 超过 2 种强调色同屏；❌ 文本带投影；❌ 直角大面板（必须圆角）；❌ UI 遮挡 3D 重演区域
